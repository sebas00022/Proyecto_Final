# Proyecto_Final
Bot de Discord sobre el cambio climatico


Este bot tiene es un cuestionario que tiene unas preguntas sobre el cambio climatico y te corrige las preguntas que fallaste.

Comandos
!start  Iniciar el cuestionario
!puntaje  Mirar puntaje maximo

Puedes responder con:
Verdadero, Falso
verdadero, falso
v   f  


Lo que el bot hace es, te pregunta distintos mitos sobre el cambio climatico y tu tiene que decir si es falso o verdadero, te dira si es correcto o no y cuando acabas te dice:
Cuantas preguntas respondiste correctamente, y te dice la respuesta correcta de las preguntas en las que fallaste.
